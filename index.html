Analytical Calculations

DAX Measures Showcase

Explore the exact DAX measures implemented in the semantic model. Built with VertiPaq efficiency and zero-division protection.

DAX: Base Iterator Measure
Total Revenue = SUMX( Sales, Sales[Quantity] * RELATED(Products[Unit Price USD]) ) -- Business Result: $55,755,479.59 -- Purpose: Evaluates row-by-row quantity against product price via relationship
DAX: Financial Performance Ratios
Gross Profit = [Total Revenue] - [Total Cost] -- Evaluates to: $32,662,688.38 Gross Margin % = DIVIDE( [Gross Profit], [Total Revenue] ) -- Evaluates to: 58.58% -- Utilizes DIVIDE() to protect against division-by-zero across filtered contexts
DAX: Omnichannel Real Estate Yield
Revenue per Square Meter = DIVIDE( CALCULATE( [Total Revenue], Stores[Channel] = "Physical Store" ), CALCULATE( SUM(Stores[Square Meters]), Stores[Channel] = "Physical Store" ) ) -- Evaluates to: $479.24 / sqm -- Isolates physical store revenue and divides by total physical retail floor area
DAX: Table-Filter Customer Retention
Repeat Purchase Rate = DIVIDE( CALCULATE( DISTINCTCOUNT(Sales[CustomerKey]), FILTER( VALUES(Sales[CustomerKey]), CALCULATE(DISTINCTCOUNT(Sales[Order Number])) > 1 ) ), [Active Customers] ) -- Evaluates to: 61.18% (7,272 repeat buyers out of 11,887 active customers) -- Iterates across unique buyers, filtering for customers with multiple orders

SQL Analysis Suite (35 Queries)

Structured interview & business intelligence SQL analysis executed and validated against the underlying dataset schema.

SQL: Advanced RFM Customer Segmentation (Window NTILE)
WITH CustomerStats AS ( SELECT c.CustomerKey, c.Name, c.Country, MAX(s.Order_Date) AS Last_Order_Date, COUNT(DISTINCT s.Order_Number) AS Frequency, ROUND(SUM(s.Quantity * p.Unit_Price_USD), 2) AS Monetary FROM Sales s JOIN Customers c ON s.CustomerKey = c.CustomerKey JOIN Products p ON s.ProductKey = p.ProductKey GROUP BY c.CustomerKey, c.Name, c.Country ), RFMScores AS ( SELECT *, NTILE(4) OVER (ORDER BY Last_Order_Date ASC) AS R_Score, NTILE(4) OVER (ORDER BY Frequency ASC) AS F_Score, NTILE(4) OVER (ORDER BY Monetary ASC) AS M_Score FROM CustomerStats ) SELECT CASE WHEN R_Score = 4 AND F_Score >= 3 AND M_Score >= 3 THEN 'Champions' WHEN F_Score >= 3 AND M_Score >= 3 THEN 'Loyal Customers' WHEN R_Score = 4 AND F_Score <= 2 THEN 'Recent New Customers' WHEN R_Score <= 2 AND F_Score >= 3 THEN 'At Risk / Churning' ELSE 'Standard Casual' END AS Customer_Segment, COUNT(*) AS Customer_Count, ROUND(AVG(Monetary), 2) AS Avg_Spend_USD, ROUND(SUM(Monetary), 2) AS Total_Spend_USD FROM RFMScores GROUP BY Customer_Segment ORDER BY Total_Spend_USD DESC;
SQL: Pareto 80/20 Revenue Concentration
WITH ProductTotals AS ( SELECT p.ProductKey, p.Product_Name, SUM(s.Quantity * p.Unit_Price_USD) AS Product_Revenue FROM Sales s JOIN Products p ON s.ProductKey = p.ProductKey GROUP BY p.ProductKey, p.Product_Name ), Ranked AS ( SELECT ProductKey, Product_Name, Product_Revenue, ROW_NUMBER() OVER (ORDER BY Product_Revenue DESC) AS Prod_Rank, COUNT(*) OVER () AS Total_Products, SUM(Product_Revenue) OVER (ORDER BY Product_Revenue DESC) AS Cumulative_Revenue, SUM(Product_Revenue) OVER () AS Total_Revenue FROM ProductTotals ) SELECT Prod_Rank, Product_Name, ROUND(Product_Revenue, 2) AS Product_Rev_USD, ROUND(Cumulative_Revenue * 100.0 / Total_Revenue, 2) AS Cumulative_Rev_Pct, ROUND(Prod_Rank * 100.0 / Total_Products, 2) AS Cumulative_Product_Pct FROM Ranked WHERE Prod_Rank IN (1, 10, 50, 100, 250, 500);
SQL: Channel Financial Comparison
SELECT st.Channel, COUNT(DISTINCT s.Order_Number) AS Orders, SUM(s.Quantity) AS Units_Sold, ROUND(SUM(s.Quantity * p.Unit_Price_USD), 2) AS Revenue_USD, ROUND(SUM(s.Quantity * (p.Unit_Price_USD - p.Unit_Cost_USD)), 2) AS Gross_Profit_USD, ROUND(SUM(s.Quantity * (p.Unit_Price_USD - p.Unit_Cost_USD)) * 100.0 / SUM(s.Quantity * p.Unit_Price_USD), 2) AS Margin_Pct, ROUND(SUM(s.Quantity * p.Unit_Price_USD) * 100.0 / 55755479.59, 2) AS Revenue_Share_Pct FROM Sales s JOIN Stores st ON s.StoreKey = st.StoreKey JOIN Products p ON s.ProductKey = p.ProductKey GROUP BY st.Channel; -- Physical Store: $44,351,154.96 (79.55%), Margin: 58.58% -- Online Channel: $11,404,324.63 (20.45%), Margin: 58.60%
SQL: Month-over-Month Revenue Growth (LAG Function)
WITH MonthlySales AS ( SELECT SUBSTR(s.Order_Date, 1, 7) AS Sales_Month, ROUND(SUM(s.Quantity * p.Unit_Price_USD), 2) AS Revenue FROM Sales s JOIN Products p ON s.ProductKey = p.ProductKey GROUP BY Sales_Month ) SELECT Sales_Month, Revenue AS Current_Month_Rev, LAG(Revenue, 1) OVER (ORDER BY Sales_Month) AS Prior_Month_Rev, ROUND((Revenue - LAG(Revenue, 1) OVER (ORDER BY Sales_Month)) * 100.0 / LAG(Revenue, 1) OVER (ORDER BY Sales_Month), 2) AS MoM_Growth_Pct FROM MonthlySales ORDER BY Sales_Month ASC;
